# DiPlay 零跑 0.2.20.1

基于上游 DiPlay `v0.2.20` 的零跑适配预览版，发布日期为 2026-10-15。源码分支：`leapmotor`；标签：`v0.2.20.1`。

本次重新编译独立安装包，应用内部版本为 **`0.2.20.1-leapmotor`**，versionCode 为 **40**。沿用包名 `com.shihab.diplay.hudtest` 和之前零跑版的签名，可覆盖安装同签名旧版并保留数据。

## 本版更新

- 完整合并上游 `v0.2.20`，保留零跑媒体来源 14、方向盘上一首／下一首／播放暂停、永久失去音频焦点后释放媒体来源、零跑名称及车标。
- 保留 2021–2023 款 C11 Dock / 原车上下栏、视频与触摸坐标、居中设置页及键盘避让适配。
- 新增仪表地图目标屏幕选择（实验性）：只列出应用可访问的非主屏公共显示器，显示 5 秒预览，经用户确认才保存。设置在下次 CarPlay 连接生效，不主动断开当前连接。
- 仪表投屏使用 CarPlay 独立地图流及导航卡片；目标消失或属性改变时停止，不尝试其他屏幕，不镜像主屏，不切换原车仪表模式。具体车机是否开放可用副屏仍需实车验证。
- 手动及后台更新渠道切换至 `buluw/DiPlay`，支持四段版本号、同名 SHA-256 校验文件、包名／签名／递增 versionCode 检查，并清理之前缓存的上游更新。
- 方控默认开启，独立诊断记录默认关闭；上游新增的方控内存日志同步遵循这个开关，关闭后保留已采集结果。

零跑接听适配、自动泊车键学习及延迟专项调试不包含在本版；相关工作继续暂缓。

## 安装与设置

在本 Release 附件中下载 `DiPlay-0.2.20.1-leapmotor-20261015.apk`。Android 7.1（API 25）及以上。

1. 覆盖安装之前同签名的零跑测试版，无需先卸载。首次升级至本版请从本 Release 下载 APK；新版本安装后使用本仓库更新渠道。
2. 方控：设置 → 车辆 → 零跑方向盘控制。
3. 仪表地图：停车后打开原车仪表投屏模式，再到设置 → 高级 → CarPlay 仪表地图 → 零跑仪表目标屏幕。确认 5 秒预览显示在预期区域，然后使用设置提示重连 CarPlay。
4. 若屏幕列表为空或预览被拒绝，请保留默认关闭状态；普通应用不能访问的私有屏幕不在支持范围内。
5. 诊断：设置 → 诊断 → 零跑方向盘诊断 → 记录方向盘诊断。复现后手动导出报告。
