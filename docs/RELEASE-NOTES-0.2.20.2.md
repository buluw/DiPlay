# DiPlay 零跑 0.2.20.2

## 本版更新

- 修正 1920×720 仪表画布与实际可见区域不一致的问题：默认使用右侧 720×720 区域，避免车标和路线落入原车界面遮挡区；支持可见区域校准，保留已保存的自定义范围。
- 新增仪表本地取景：可选择完整画面或局部取景，调整水平中心、垂直中心和放大比例，修正画面偏移及缩放；取景调整在车机端生效。
- 新增仪表“同步主屏”来源：将现有 CarPlay 主屏画面投到仪表，无需向 iPhone 请求独立仪表地图流。
- 修正仪表视频比例：独立地图使用自身协商分辨率，显示时读取实际解码尺寸并排除编码补齐区域，减少拉伸、留黑和裁切计算错误。
- 修复后台仅镜像解码时实际尺寸未更新的问题；忽略已移除、替换、关闭或退出的旧解码器通知，避免重连后被旧尺寸覆盖。

仪表可见区域、画面来源和本地取景设置保存后，需重新连接 CarPlay 才生效。独立地图导航状态及主屏车道级显示的兼容性仍需实车验证。
