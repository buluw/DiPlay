# DiPlay 零跑 0.2.19

基于上游 DiPlay `v0.2.19` 的零跑适配预览版，发布于 2026-10-15。源码分支：`leapmotor`；标签：`v0.2.19-leapmotor`。

## 本版功能

- 零跑方向盘控制：上一首、下一首、播放／暂停，默认开启；升级时保留已经保存的开关选择。
- 自动上报媒体来源 14、当前歌曲与播放状态；只转发来源 14 的有效方向盘媒体按键。永久失去音频焦点后释放媒体来源，避免抢占原车媒体。
- 独立诊断开关默认关闭；开启后才记录，关闭不影响方控。关闭记录后重连也保留已采集结果，可手动导出。
- 应用名称为“DiPlay 零跑”；CarPlay 返回原车按钮使用零跑图标和“Leapmotor”名称。
- 保留原车上下栏时统一视频、触摸和侧栏的可用区域，修复侧栏拖动偏移，并处理设置界面和安全区编辑器的键盘避让。

## 安装与设置

在 Release 附件中下载 `DiPlay-0.2.19-leapmotor-20261014.apk` 并安装到车机。

- 应用版本：`0.2.19-leapmotor`，versionCode：`38`，Android 7.1（API 25）及以上。具体车型和固件兼容性仍需验证。
- 包名：`com.shihab.diplay.hudtest`。保留此前零跑版包名与 Android debug 签名，可直接覆盖之前同签名的零跑测试版并保留数据。
- 方控：设置 → 车辆 → 零跑方向盘控制。
- 排查：设置 → 诊断 → 零跑方向盘诊断 → 记录方向盘诊断。
- 需要原车上下栏常驻时，关闭“隐藏状态栏”和“隐藏导航栏”，并取消应用管家针对 DiPlay 的沉浸规则。
